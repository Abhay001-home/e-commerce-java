## ✅ PHASE 1 — COMPLETE: Project Setup & Foundation

### Infrastructure
✅ Spring Boot 3.2.5 Maven project (Java 17)
✅ MySQL database connection (localhost:3306/ecommerce_db)
✅ application.yml — datasource, JWT, mail, file upload, Swagger
✅ BCrypt(12) password encoding
✅ CORS configuration (localhost:5173 / localhost:3000)

### Entities (JPA)
✅ User entity (with roles, addresses, audit timestamps)
✅ Role entity (ROLE_USER, ROLE_ADMIN)
✅ Address entity (HOME/OFFICE/OTHER, default flag)

### Repositories (Spring Data JPA)
✅ UserRepository (findByEmail, existsByEmail, findByEmailWithRoles)
✅ RoleRepository (findByName)
✅ AddressRepository (findByUserId, clearDefaultByUserId bulk update)

### DTOs
✅ RegisterRequest (with Bean Validation)
✅ LoginRequest (with Bean Validation)
✅ AddressRequest (with Bean Validation)
✅ ChangePasswordRequest (with Bean Validation)
✅ AuthResponse (access token, refresh token, user info)
✅ UserDTO (safe user representation, no password)
✅ AddressDTO
✅ ApiResponse<T> (generic response wrapper with Factory Methods)

### Security (JWT + Spring Security)
✅ JwtUtil (Singleton) — generate, validate, extract claims (HMAC-SHA256)
✅ JwtAuthenticationFilter (OncePerRequestFilter, Chain of Responsibility)
✅ CustomUserDetailsService (loads user by email, maps roles to authorities)
✅ SecurityConfig — RBAC, stateless sessions, filter chain, CORS

### Services
✅ AuthService — register, login, token refresh
✅ UserService — profile CRUD, address CRUD, change password

### Controllers
✅ AuthController — POST /auth/register, /auth/login, /auth/refresh
✅ UserController — GET/PATCH /users/me, address CRUD at /users/me/addresses

### Exception Handling
✅ ResourceNotFoundException (404)
✅ BadRequestException (400)
✅ ForbiddenException (403)
✅ GlobalExceptionHandler (@RestControllerAdvice) — validation, security, generic

### Documentation
✅ SwaggerConfig — OpenAPI 3.0, JWT bearer auth in Swagger UI
✅ Accessible: http://localhost:8080/api/swagger-ui.html

### Database
✅ sql/schema.sql — full schema (all phases: Users→Reviews)
   Tables: roles, users, user_roles, addresses, categories, brands,
           products, product_images, product_variants, product_specifications,
           inventory, coupons, carts, cart_items, wishlists, wishlist_items,
           orders, order_items, payments, shipments, order_status_history, reviews
✅ Seed data: admin user, sample categories, sample brands

## 🔧 KNOWN CONFIGURATION NOTES

1. **MySQL**: Run sql/schema.sql before starting the app
   Default: localhost:3306/ecommerce_db, root/root
   Change in: backend/src/main/resources/application.yml

2. **JWT Secret**: Change in production! Current dev secret in application.yml
   Set env var: JWT_SECRET=<your-256-bit-base64-key>

3. **Email**: Stubbed with console logging by default
   Set env vars: MAIL_USERNAME, MAIL_PASSWORD for real SMTP

4. **Swagger UI**: http://localhost:8080/api/swagger-ui.html
   Login first at /auth/login, copy token, click Authorize in Swagger

5. **File Uploads**: Stored in backend/uploads/ by default

6. **BCrypt strength**: Set to 12 (production-grade). Reduce to 10 for tests.
